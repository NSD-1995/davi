# Product Requirements Document (PRD)

## Product
DAVI — Dynamic AI for Visionary Institutions

## Product Summary
DAVI is a school operating system designed to help institutions manage classroom operations and learning workflows through AI assistance.

## Target Users
1. Teachers
2. School Administrators
3. Parents / Guardians
4. Academic Coordinators

## Problem Statement
Schools currently manage attendance, homework, lesson planning, and communication through disconnected systems. This leads to delays, missed follow-up, inconsistent records, and reduced visibility.

## Goals
- Centralize school operational workflows
- Reduce manual admin work for teachers
- Improve accountability through reliable records
- Enable AI-guided lesson planning and school communication

## User Roles
### Teacher
- Mark attendance
- Assign and review homework
- Generate lesson plans with AI
- Communicate with parents

### Administrator
- Manage users and school structure
- Track attendance and operational trends
- Configure policies and alerts

### Parent
- View attendance updates
- Monitor homework and learning progress
- Receive notifications and reminders

## User Stories
### Teacher
- As a teacher, I want to mark attendance quickly so that I can spend more time teaching.
- As a teacher, I want AI-generated lesson ideas so that planning is faster.
- As a teacher, I want homework tracking so that I can follow up with students consistently.

### Parent
- As a parent, I want notifications about attendance and homework so that I can stay informed.

### Administrator
- As an administrator, I want a unified dashboard so that I can view school-wide operational health.

## Feature List
- Teacher attendance management
- Homework assignments and status tracking
- AI lesson generation support
- Parent notification workflows
- Role-based access control
- Dashboard insights for administrators

## Functional Scope (MVP)
- Teacher attendance management
- Homework assignments and status tracking
- AI lesson generation support
- Parent notification workflows
- Role-based access control
- Dashboard insights for administrators

## Non-Functional Requirements
- High availability for daily school operations
- Secure access control
- Data consistency and auditability
- Multi-platform access (web + mobile)
